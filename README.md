# Sistema de Gestión de Alumnos (MVCAlumnos)

## Descripción del Proyecto
Aplicación web desarrollada bajo el patrón de arquitectura Modelo-Vista-Controlador (MVC) para la gestión administrativa de alumnos. Permite realizar operaciones CRUD completas, búsquedas avanzadas y gestión de inscripciones de manera eficiente.

## Características Principales
*   **Gestión de Alumnos:** Registro, edición, eliminación y visualización de datos de estudiantes.
*   **Búsqueda y Filtrado:** Búsqueda por nombre, matrícula o carrera.
*   **Validación de Datos:** Formularios con validación del lado del cliente y servidor.
*   **Interfaz de Usuario:** Diseño limpio y responsivo utilizando Bootstrap.

## Tecnologías Utilizadas
*   **Framework:** C#, ASP.NET Core MVC
*   **ORM:** Entity Framework Core
*   **Base de Datos:** SQL Server
*   **Frontend:** Razor Views, HTML5, CSS3, Bootstrap, JavaScript
